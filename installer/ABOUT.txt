This installer will:

  1. Check for Python 3.10+ and install it automatically via winget
     (Windows Package Manager) if it isn't already present.
  2. Check for the GTK3 runtime (required for PDF report generation)
     and install it automatically via winget if missing.
  3. Create a private Python virtual environment inside the install
     folder and install every required Python package into it —
     nothing is installed into your system Python.
  4. Install Fluetix itself (front end + backend) and create Start
     Menu / Desktop shortcuts.

An internet connection is required for steps 1-3. No purchase, account,
subscription, or payment of any kind is involved anywhere in this process
— every component installed is free and open source.

Uninstalling Fluetix later removes the application, its virtual
environment, and its shortcuts. Python and the GTK3 runtime are left
in place, since other software on your system may also depend on them
— this is standard behavior for shared system components.
